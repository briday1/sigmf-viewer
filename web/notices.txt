SigMF Viewer browser distribution
=================================

Bundled recordings are copied byte-for-byte. The original metadata, including
authors, license fields, and descriptions, accompanies every sample file.
The build verifies every file against scripts/download_data.py.
No LTE recording is included.

Corresponding source: https://github.com/plotly/plotly.js/tree/v3.1.0

The runtime distributions above are not modified. Python application source is
included in sigmf_viewer.zip. Package versions and artifact SHA-256 digests are
recorded in build-info.json. All application/runtime/data requests made while
viewing recordings are same-origin; this file's external links are references,
not runtime dependencies.
